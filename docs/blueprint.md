# **App Name**: MediLexicon Assistant

## Core Features:

- Secure Login: Implement a secure login using hardcoded credentials for demo purposes.
- Diagnosis Mapping Form: Create a form where users can input Patient ID, select the medical system, and enter the diagnosis.
- AI-Powered Autocomplete: As the user types a diagnosis, call the 'suggestDiagnoses' AI tool to provide real-time diagnosis suggestions.
- Dual-Code Mapping: Submit the diagnosis to the 'suggestIcdCodes' AI tool. This tool analyzes the diagnosis to provide an accurate ICD-11 MMS code and ICD-11 TM2 code.
- Detailed Results Display: Present the results with the original query details, suggested MMS and TM2 codes with descriptions, and an AI-generated condition description by stages.
- Structured Recommendations: Display AI-generated recommendations, including lifestyle, diet, and therapeutic suggestions based on the traditional system.
- Reporting and Integration: Include a button to "Download Report" as a text file, demonstrating potential integration into clinical workflows.

## Style Guidelines:

- Primary color: Light, desaturated purple (#D0B8E1) to reflect medical and traditional concepts.
- Background color: Very light gray (#F5F5F5) to ensure readability and a clean interface.
- Accent color: Soft blue (#A7D1E7) to draw attention to key interactive elements and CTAs without overwhelming the interface.
- Body and headline font: 'Inter', a sans-serif font, will be used to maintain a modern and machined UI.
- Use a set of simple, outline-style icons that are visually consistent.
- Maintain a clean, spacious layout to avoid visual clutter, aiding the readability of diagnosis details and AI-generated content.
- Incorporate subtle transitions and loading animations to improve user experience, particularly during AI-driven processes such as diagnosis suggestion and code mapping.
